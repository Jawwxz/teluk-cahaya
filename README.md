An original open-world crime game built for the [make.fun](https://make.fun/bounty/gta6-01) GTA 6 bounty — a sun-soaked fictional coastal city to explore on foot and by car, with traffic, pedestrians, a wanted level, missions and a story. Built with three.js; everything loads offline from static files, all art, names, story and sound invented for this game.
